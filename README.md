# RideDash

RideDash is a native iOS motorcycle navigation and ride companion project.

The project is being developed phase-by-phase, starting with hardware connectivity and diagnostics, then protocol/session interoperability, projection, navigation rendering, input handling, ride resilience, and product features.

## Current status

- Project planning: in progress
- Phase 0 — hardware baseline: ready for test data
- Phase 1 — iOS Wi-Fi connectivity & diagnostics: implementation starting

See [`Docs/PROJECT_PLAN.md`](Docs/PROJECT_PLAN.md) for the complete roadmap.

## Safety boundary

RideDash is limited to infotainment/navigation interoperability. It does **not** implement ECU, throttle, braking, ABS, immobilizer, traction-control, or other safety-critical vehicle control.
